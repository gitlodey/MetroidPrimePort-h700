# Обязательный ориентир для всех coding agents

Отвечай по-русски. Главная цель — **воспроизводимо собрать и запустить новую игру на ANBERNIC RG40XX H / H700 под muOS 2601.0 Jacaranda** с корректными графикой, интерфейсом, управлением, звуком и сохранениями. Оптимизация FPS — отдельный следующий этап.

**ДО любого действия, исследования, гипотезы, теста или делегирования сверяй его с этой целью.** Нужна конкретная цепочка: цель → риск/вопрос именно целевого пути → минимальная необходимая проверка → решение, которое изменится по результату → условие завершения. Без такой связи работу не начинать. Служебные чтения, правки и проверки тоже должны прямо обслуживать текущий запрос или согласованный шаг.

Полнота собственной тестовой матрицы, любопытство и идеальность вспомогательного инструмента — не цели проекта. Проблема тестового backend не равна проблеме H700. Не расширяй окружение, зависимости или объём ради проверки случая, необходимость которого для RG40XX H не установлена. При новом затруднении сначала повтори проверку связи с целью, а не автоматически углубляй отладку.

Обязательно прочитай [CLAUDE.md](CLAUDE.md), [правила работы](docs/H700_WORKFLOW.md) и [текущий статус](docs/H700_PROGRESS.md). Канонический фильтр действий и разбор ошибки с Null backend — в workflow. Не изменяй production code без утверждённого плана, не продолжай при необходимости его изменения без согласования. Это правило не разрешает скрывать ошибки, отключать meaningful tests или ослаблять корректность/безопасность ради продвижения.

Соседний `MetroidPrimePort` — донор только для чтения; изменения делаем здесь. Без отдельного разрешения не подключайся к приставке и не запускай device tests. Сохраняй посторонние local/untracked changes.
