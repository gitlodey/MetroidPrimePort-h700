# H700 — прогресс переноса

**Цель:** новая база игры работает на **ANBERNIC RG40XX H / muOS 2601.0 Jacaranda** с корректными графикой, интерфейсом, управлением, звуком и сохранениями. Оптимизация к 30 FPS при 640×480 — следующий отдельный этап.

**Текущий этап:** подготовка плана; [отдельный Docker builder и демка](H700_BUILD_ENVIRONMENT.md) собраны и прошли контейнерные проверки ENV-01/02. План реализации переноса ещё не утверждён; game/platform code не менялся.

## Готово

- Исследованы оба донорских коммита и новая база `v0.46.0`; подготовлены [полный отчёт](H700_PORT_REVIEW.md), [короткая версия](H700_PORT_SUMMARY.md) и справочники платформы.
- Зафиксировано: вывод на H700 уже проверен в старом порте; выбирать нужно способ интеграции с новой архитектурой.
- Записаны [правила итераций и изменения плана](H700_WORKFLOW.md), [предплановые проверки](H700_PREFLIGHT.md) и [находки для будущей оптимизации](H700_OPTIMIZATION_NOTES.md).
- Найден точный Dawn ref в `Timdeuces/dawn`; выполнен [статический разбор EGL/import/sync](H700_DAWN_EGL_RESEARCH.md).
- Read-only SSH: сохранён [firmware ABI snapshot](H700_RUNTIME_ABI.md) — 46 SONAME entries и транзитивные зависимости. Все пять symbols прежнего link failure на приставке есть.

- **ENV-02:** [демка](H700_GRAPHICS_PROBE.md) слинкована; **43/43 tests**, ELF/provider/version/selected-symbol gate, container `ldd`, `--help` и CPU `--self-test` — PASS. Stage с manifest и licenses готов; deploy/graphics не выполнялись.
